FREE PUBLISHING:
1. Create a free GitHub account at github.com if you don't have one.
2. Create a new PUBLIC repository, e.g. "vardhaman-trading-website".
3. Upload all four website files.
4. Open Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select "main" and "/ (root)", then Save.
7. GitHub will give you a free website address ending in github.io.

Alternative:
You can upload this folder to a free static-hosting service such as Netlify.
